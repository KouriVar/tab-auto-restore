# 标签页自动恢复

一个极简 Chrome/Chromium Manifest V3 标签恢复扩展。

## 功能

- 按标签和窗口变化事件保存最近一次有效会话
- 浏览器启动后自动恢复上次保存的标签
- 所有普通窗口关闭后，再次打开普通窗口时自动恢复上次保存的标签
- 自动过滤 `chrome://`、`about:`、空白页等无效页面
- 恢复期间暂停保存，避免恢复过程覆盖上次会话

## 当前取舍

- 不恢复标签组
- 不提供侧边栏交互
- 不保留历史快照
- 不记录执行日志

## 隐私

扩展只在浏览器本地保存最近一次有效标签页会话，不上传、不共享、不出售用户数据。详见 [Privacy Policy](PRIVACY.md)。

## 使用

1. 打开浏览器扩展管理页
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择当前文件夹
